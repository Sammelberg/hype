# Роутер скиллов

Загруженные скиллы — это `.claude/skills/` проекта и `~/.claude/skills/` пользователя.
Библиотека (`.claude/skills-library/`, ~460 скиллов) лежит рядом и в контекст не попадает.
Это локальные симлинки на `~/Schreibtisch/claude/.claude/` — не в git, в CI их нет.

Твоя работа: по формулировке задачи найти в библиотеке подходящие скиллы и прочитать их.

## Как пользоваться

```bash
python3 .claude/skills/skill-router/scripts/route.py "анимация появления карточек при скролле"
```

Запрос своими словами, можно по-русски. Вывод:

- **ПОДКЛЮЧИТЬ ИЗ БИБЛИОТЕКИ** — путь к `SKILL.md`. **Прочитай файл через Read.**
  Копировать не нужно: прочитанный скилл работает так же, как загруженный.
- **УЖЕ В ЯДРЕ** — скиллы из `.claude/skills/` проекта, они уже доступны.

Флаги: `-n 15` больше результатов · `--cat web-effects` одна категория ·
`--list-cats` категории · `--show <имя>` карточка скилла.

Если библиотеки нет (`.claude/skills-library/` отсутствует или пуст) — восстанови её:

```bash
.claude/skills/skill-router/scripts/link-library.sh
```

Скрипт пересоздаёт симлинки и индекс; источник не меняет. Путь к источнику можно задать
через `SKILL_LIBRARY_SRC`.

## Порядок работы

1. **Сначала таблица в CLAUDE.md.** Роутер — для того, что ей не покрыто.
2. **Прогони запрос через роутер**, прочитай 1–3 верхних совпадения. `+ references/…`
   читай только на соответствующем шаге.
3. **Если выдача мимо** — переформулируй или сузь категорией. Пусто — значит, этого нет.
4. **Скажи пользователю, что подключил**, одной строкой.

## Правила проекта сильнее скилла

Библиотека общая, не под этот проект. Прочитав скилл, сверь его с CLAUDE.md:

- **Суверенитет данных.** Скиллы, которые тянут внешние сервисы или CDN — Unsplash,
  Aura Assets, UIZZE (`anti-ui-slop`), ElevenLabs, GPT Image, Gemini, Vanta.js,
  Unicorn Studio, globe.gl с удалёнными текстурами, Iconify API, Google Fonts —
  нарушают CSP и правило «данные не покидают нашу инфраструктуру». Бери из них идею,
  ассеты — только локально; новый внешний источник — только с согласия.
- **Стек.** Next.js 16 + Payload + Tailwind v4 + shadcn (radix). Скиллы под Vue, Svelte,
  Expo, SwiftUI, Base UI (`migrate-radix-to-base`) здесь не применяются.
- **Анимация.** `motion/react` для UI, GSAP + Lenis только для скролла и таймлайнов,
  никогда оба на одном элементе. Скилл, предлагающий иначе, в этом месте не слушай.
- **Язык.** Весь видимый текст — немецкий. Для текстов: `copywriting-de`,
  `vermenschlichen`.
- **Стили** (`styles/*`) — только по явной просьбе или выбранному арт-директу, как
  `minimalist-ui` и `industrial-brutalist-ui`.
- **Новые зависимости** — только с согласия, даже если скилл их требует.

## Категории

| Категория            | Когда сюда смотреть                                                              |
| -------------------- | -------------------------------------------------------------------------------- |
| `web-effects`        | Приём или эффект: скролл-сцены, reveal, маски, маркизы, Three.js, WebGL          |
| `kern`               | Ядро исходной библиотеки: `impeccable`, `better-*`, `improve-animations`, GSAP-* |
| `ux-research`        | Законы UX, гештальт, критика по осям, IA, формы, состояния загрузки              |
| `styles`             | Конкретный визуальный язык — только по просьбе                                   |
| `marketing`          | SEO, конверсия, соцсети; немецкие DACH-версии (`competitors`, `social`, …)       |
| `media`              | Брендинг, баннеры, слайды (генерация картинок — внешние сервисы, см. выше)       |
| `meta-tooling`       | Аудит AI-slop, оптимизация анимаций, скриншоты страниц                           |
| `workflow`           | Спека → тикеты → реализация, мерж-конфликты                                      |
| `native`, `game-dev` | Для этого проекта не нужны                                                       |

## Чего не делать

- **Не читай больше 3–4 скиллов на задачу** — они противоречат друг другу.
- **Не подменяй роутером загруженные скиллы.**
- **Не копируй в `.claude/skills/` без нужды** — каждое описание стоит контекста в каждой
  сессии. Если скилл нужен постоянно: `cp -r` из `~/Schreibtisch/claude/.claude/…` в
  `.claude/skills/`, затем `link-library.sh`. Если имя совпадает со скиллом в
  `~/.claude/skills/`, переименуй (`name:` с суффиксом) — пользовательский скилл
  перекрывает проектный.
