# CMS section

A change to what the site is made of touches up to nine places; a skipped one surfaces later as a CI failure (missing migration), an empty page (no seed), stale content (no revalidation) or a document that search, redirects and the sitemap never see (no path). Work through the steps in order; each ends on its completion criterion. Pick the shape first:

- **Homepage section** (one instance, edited in one place): a field or list in `SiteSettingsSchema` (`src/cms/content/types.ts`, stored as one jsonb document), rendered in `src/app/(frontend)/page.tsx`, edited in `src/app/(admin)/admin/(app)/einstellungen/_components/settings-editor.tsx`. No migration.
- **Field on pages or projects**: a column in `src/cms/db/schema.ts`, a field in `PageInputSchema` / `ProjektInputSchema`, mapped in `content/pages.ts` (`inputOf`, `columnsOf`, `toPage`), rendered in `[...slug]/page.tsx`, edited in the page editor.
- **Routed collection** (documents with their own URL, e.g. `posts` → `/beitraege/[slug]`): a table, a repository, a route, an admin section; step 5 applies.
- **Unrouted collection** (data shown elsewhere, e.g. team members): table, repository, admin section; skip step 5.

## Steps

1. **Schema.** Add the column or table to `src/cms/db/schema.ts` (snake_case columns come from the drizzle `casing`; relative imports only). A draftable, public document copies the `documentColumns` and `seoColumns` of `pages`. Then `pnpm migrate:create <snake_case_name>`; open the SQL in `src/cms/migrations/`, and `pnpm migrate`. Done when the migration applies to the local database and `pnpm migrate` is idempotent.
2. **Types and validation.** The input shape is a zod schema in `src/cms/content/types.ts` (German messages, Anrede „Sie“); the document type the site reads sits beside it. Done when `pnpm typecheck` passes.
3. **Repository.** Reads and writes live in `src/cms/content/<name>.ts`, modelled on `projekte.ts`: `listPublished…`, `get…(draft)`, `create…`, `save…Draft`, `publish…` (records a version via `addVersion`, returns the paths before and after), `unpublish…`, `delete…`, `upsertPublished…` for the seed. Errors the admin should show are thrown as a `<Name>Error` with a `field`, and added to `known()` in `src/app/(admin)/admin/_actions/client.ts`. A `*.db.test.ts` next to it (see `pages.db.test.ts`: `describe.skipIf(!DATABASE_URL)`, `test-` prefix, cleanup). Done when the tests pass against the local database.
4. **Query and render.** The site reads only through `src/data/queries.ts` (React `cache`, `draftMode()` for previewable documents). A section renders nothing when its content is empty, gets an `aria-labelledby` heading, and follows the styling rules in CLAUDE.md. A routed collection's page calls `redirectOrNotFound(path)` for a missing document and exports `generateMetadata` via `buildMetadata` (`src/lib/seo.tsx`). Done when the page renders with the content empty and filled.
5. **Path (routed collections only).** Add `<name>Path` to `routedCollections` in `src/cms/paths.ts` (pure, no db import: client components use it), list the documents in `src/app/sitemap.ts`, and, if they should be found, add their table to the UNION in `src/cms/content/search.ts` (a generated `search tsvector` column like `projekte`'s). Done when the document appears in `/sitemap.xml` and `/suche` finds it after publishing.
6. **Admin.** A section under `src/app/(admin)/admin/(app)/<name>/`: a list page, `neu`, `[id]`, and an editor client component that copies `projekte/_components/projekt-editor.tsx` (react-hook-form + zod, `EditorShell`, `useAutosave`, `PreviewPane`, `VersionsSheet`). Actions in `src/app/(admin)/admin/_actions/<name>.ts` on `authActionClient`: input schema, repository call, `revalidateDocument(paths)`. Add the section to `NAV_CONTENT` or `NAV_SITE` in `_components/nav.ts` and its documents to the palette entries in `(app)/layout.tsx`. Done when create, autosave, publish, unpublish, restore and delete work in the running app.
7. **Revalidation.** Publishing calls `revalidateDocument([...pathsBefore, ...pathsAfter])` (`src/cms/revalidate.ts`); settings call `revalidateSite()`; documents that feed fixed paths add those paths. Done when publishing in `/admin` updates the running page without a rebuild.
8. **Seed.** German content (Anrede „Sie“) in `scripts/seed-data.ts`, upserted in `scripts/seed.ts`; a new route also goes into `SEED_PATHS`, which feeds the smoke, a11y and data-sovereignty tests. Done when `pnpm seed` runs twice without error on a scratch database (`createdb` in the container, `DATABASE_URL=… pnpm exec tsx --env-file=.env src/cms/db/migrate.ts && … scripts/seed.ts`).
9. **Checks.** New interactive UI goes through `better-accessibility`; an e2e case joins `e2e/admin-editors.spec.ts` or `admin-ops.spec.ts` (sign in with `signIn` from `e2e/_admin.ts`, create with an „E2E“ prefix, delete at the end; `scripts/clean-e2e.ts` removes leftovers). Done when the Definition of done in CLAUDE.md holds.
